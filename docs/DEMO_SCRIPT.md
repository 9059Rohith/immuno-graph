# Three-Minute Judge Demo Script

Use a clean browser tab and the deployed public URL. Keep a local recording fallback ready, but never substitute an unverified URL in the submission.

## 0:00–0:20 — The problem

“Epitope tools can produce many disconnected scores. ImmunoGraph turns one protein sequence into an auditable shortlist while preventing an LLM from inventing biological evidence.”

Show the landing headline, Track 4 label, and trust proof points. Select **Launch judge demo**. Point out that no email or password is requested.

## 0:20–0:45 — Safe, reproducible input

Show the synthetic-input label, protein SHA-256, 24-hour Judge Mode badge, and six-step rail.

“Every launch creates an isolated workspace backed by a reviewed synthetic fixture. It is demonstration-only and expires automatically.”

Open **Configure**. Approve the curated configuration snapshot.

## 0:45–1:15 — Agent orchestration

Start the approved run and open the workflow.

“The domain agent coordinates typed prediction, normalization, evidence, constraint, ranking, coverage, and report capabilities. The LLM has no authority to create scores or waive rules.”

Point out recorded stages and the `FIXTURE` source badge.

## 1:15–1:50 — Evidence and abstention

Open **Candidates**. Select the top eligible candidate, then open **Shortlist approval**.

“Unlike tracks are ranked separately. Raw evidence, normalized values, constraints, rejection states, and deterministic explanations remain inspectable. Missing evidence is unavailable—not guessed.”

Acknowledge the computational-only status and approve the shortlist.

## 1:50–2:30 — Scientific Trust Center

Open **Trust Center**.

“This is the key differentiator. ImmunoGraph does not show a made-up trust percentage. It evaluates six independent claims from stored records: fixture integrity, connector provenance, constraints, human gates, artifact hashes, and visible abstention.”

Show the configuration hash, manifest hash, source table, and approval snapshots. Mention that report hashes are unavailable until a report exists.

## 2:30–2:50 — Reproducible export

Select **Continue to reports**, generate the report, and show the download links and SHA-256 column.

“The report, rejected candidates, evidence graph, and workflow trace are downloadable, content-addressed artifacts.”

## 2:50–3:00 — Close

“ImmunoGraph is not claiming a vaccine or validated biology. It is a safer pattern for domain agents: typed tools, deterministic rules, explicit fallback, provenance, abstention, and human approval.”

## Recording fallback

If a hosted service cold-starts, pause before the timed take and warm the landing, API health, and MCP health endpoints. If the live run still fails, show the already verified fixture run and disclose the failure; do not edit the video to imply a successful action that did not occur.
