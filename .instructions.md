# Repository Rules

This repository follows documentation-driven development.

Before writing code always read:

README.md

PROJECT_SPEC.md

ARCHITECTURE.md

IMPLEMENTATION_PLAN.md

TASKS.md

Never invent architecture.

Never invent APIs.

Never invent MCP tools.

Never invent algorithms.

Everything must match the specification.

## Coding

Use strict TypeScript.

Prefer small modules.

Prefer composition over inheritance.

Avoid long functions.

Avoid duplicated logic.

No TODO placeholders.

No commented-out code.

No dead code.

## Tests

Every deterministic algorithm must have unit tests.

New features require tests.

## Logging

Log:

start

finish

failure

duration

tool name

workflow id

## Documentation

If implementation changes behavior:

update documentation.

## Scope

Never add:

authentication

multi-tenancy

AI-generated biology

drug discovery

molecular dynamics

Never replace deterministic algorithms with LLM reasoning.

LLMs may only generate explanations and reports.
